# Verifierad feature availability

Kontrollerad mot Valmyndighetens officiella sidor och filer 2026-09-10.
`✓` betyder verifierad officiell fil, `—` att uppgiften saknas eller ännu inte
kan finnas, och `SCB` att variabeln måste hämtas från en annan myndighet.

| Feature | 2006 | 2010 | 2014 | 2018 | 2022 | 2026 |
|---|---:|---:|---:|---:|---:|---:|
| Slutligt RD-resultat per valdistrikt | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| Giltiga/ogiltiga röster | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| Röstberättigade i resultatfil | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| Röstberättigade efter ålder/kön | — | ✓ | ✓ | ✓ | ✓ | ✓ |
| Valdeltagande | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| Valdistriktspolygon | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Officiell mapping från föregående val | — | — | — | ✓ | ✓ | ✓ |
| Utbildning | SCB | SCB | SCB | SCB | SCB | SCB |
| Inkomst | SCB | SCB | SCB | SCB | SCB | SCB |
| Boende | SCB | SCB | SCB | SCB | SCB | SCB |

## Viktiga begränsningar

- Valdagen 2026 är 13 september. Resultatindexet finns, men är fortfarande tomt.
- Ingen officiell mapping hittades för 2006→2010 eller 2010→2014.
- 2014→2018 har en kvantitativ mapping med överlappningsprocent.
- 2018→2022 och 2022→2026 anger jämförbarhet, men inte areal- eller
  befolkningsvikter.
- 2006-geometrin använder RT90 2.5 gon V. Senare filer använder SWEREF 99 TM.
- 2022-geometri publiceras i 21 länsfiler och saknar en rikstäckande fil.
- 2018 års fullständiga XML är gallrad; XLSX är den praktiska primärkällan.
- Valmyndigheten publicerar ålder och kön, men inte socioekonomiska
  valdistriktsfeatures.
